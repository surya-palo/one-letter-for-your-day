Entry for the [One Letter for Your Day](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36) bounty on make.fun.

The entry is exactly one character — a letter from A to Z — and nothing
else: no word, no gloss, no punctuation. Behind that letter sits a word
that describes the day. The program writes the single letter to
`/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Python 3, standard library only. No network, no secrets, no input.
